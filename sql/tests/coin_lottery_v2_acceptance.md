# Coin + Number Lottery V2 — acceptance checklist

ใช้กับฐานทดสอบเท่านั้น หรือใช้ transaction ที่ลงท้ายด้วย `ROLLBACK` ห้ามสร้างสลาก/เหรียญทดสอบในข้อมูลจริง

## อัตโนมัติแล้ว

- Migration ทั้งไฟล์รันได้บน schema ปัจจุบันภายใน `BEGIN … ROLLBACK`
- `sql/tests/coin_lottery_v2_transaction_test.sql` ตรวจ ledger idempotency, reversal, ยอดไม่ติดลบ และสูตรปัดจำนวนสลาก
- JavaScript ใน `index.html` ผ่าน syntax check

## ต้องทดสอบ end-to-end หลังติดตั้ง migration บน staging

1. ครูเจ้าของวิชา/ครูร่วมเห็น assignment ของตน ส่วนครูอื่นถูก RPC ปฏิเสธ
2. นักเรียนเห็นเฉพาะ assignment ที่ลงทะเบียนและข้อมูลส่วนตัวของตน
3. บันทึก `present` ซ้ำไม่แจกเหรียญซ้ำ; เปลี่ยนเป็น late/absent/leave สร้าง reversal
4. โบนัสสัปดาห์ได้เฉพาะ present ครบทุก session; cancelled ไม่นับ
5. เปิดโมดูลกลางภาคแจก opening balance ครั้งเดียวและไม่เข้าอันดับ
6. นักเรียน 30/35/40/41 คนได้แผง 100/108/120/124 ใบ และเลข `00`, `000` แสดงศูนย์นำหน้า
7. สองบัญชีจองใบเดียวกันพร้อมกัน มีเพียงบัญชีเดียวสำเร็จ
8. ตะกร้าเกิน 10 ใบ, หมด 2 นาที, เหรียญไม่พอ หรือมีใบใดไม่ว่าง ต้อง rollback ทั้งตะกร้า
9. กดซื้อซ้ำ/refresh คืน purchase เดิมและไม่หักเหรียญซ้ำ
10. หลังเวลาปิดขาย หน้าเดิมซื้อไม่ได้ และสลากชนิดที่หมดไม่กระทบอีกชนิด
11. โหมดทดลอง draw/wheel ไม่เพิ่มแถวข้อมูลจริง
12. ผลจริงบันทึกทีละ slot; ปิดหน้าแล้วกลับมาต่อโดยไม่สุ่ม slot เดิมใหม่
13. draw เลือกจากเลขที่ขายแล้วแบบ distinct; A/B ไม่เพิ่มน้ำหนัก และเลข 2 ตัวสองครั้งซ้ำได้
14. สิทธิ์วงล้อเท่ากับจำนวนใบที่ตรงผลแต่ละ slot และสิทธิ์เดิมหมุนซ้ำไม่ได้
15. คูปองใช้ครั้งเดียว, คะแนนรวมต่องวดไม่เกิน 3, และหมดอายุหลัง 3 วันเรียน
16. CSV/PDF และ dashboard ไม่แสดงข้อมูลข้าม assignment; นักเรียนไม่เห็นยอดเหรียญหรือชื่อผู้ซื้อของเพื่อน
